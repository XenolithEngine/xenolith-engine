# Поддержка платформ

## Linux

- Минимальная версия ядра: 5.10

Варианты:
- glibc: минимальная версия: 2.33
- musl: в разработке

Архитектуры:
- amd64
- arm64
- riscv64
- loongarch  (в разработке)

## Android

- Минимальная версия ОС: android-24

Варианты:
- NDK: минимальная версия: r29
- AOSP: начиная с android-29

Архитектуры:
- amd64
- arm64
- x86 (*)
- armv7-a (*)
- riscv64 (в разработке)

(*) - поддержка на уровне Xenolith Runtime есть, но практических устройств для использования этих архитектур нет.

## Windows

- Минимальная версия ОС: Windows 10 1703 (build 15063)
- Минимальная версия Wine: 9.0

Архитектуры:
- amd64
- arm64 (в разработке)

## MacOS

- Минимальная версия: 14.4

Архитектуры:
- amd64
- arm64

## iOS (в разработке)
